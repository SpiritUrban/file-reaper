# Assets

Іконки застосунку та ресурси інсталятора.

Фінальні іконки генеруються перед T-159 (інсталятор); `bundle.active = false`
у `core/shell/tauri.conf.json`.

Примітка: `core/shell/icons/icon.ico` — тимчасова згенерована заглушка
(32×32, бурштинова точка на темному): tauri-build вимагає .ico для
Windows Resource навіть без бандлінгу. Замінюється у T-159.
