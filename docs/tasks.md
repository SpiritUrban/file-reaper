## 0. Легенда

**Оцінка складності:** `S` — до 1 дня · `M` — 2–3 дні · `L` — 4–7 днів (одна пара рук).

**Залежності:** ID задач, які мають бути завершені до старту. `—` = можна починати одразу (в межах свого місця у порядку). Задачі без взаємних залежностей усередині фічі можуть виконуватись паралельно.

**Критерії завершення (DoD):** перевірюване твердження; задача або відповідає йому, або не закрита. Для всіх задач Core неявно діє: код покритий тестами відповідного рівня і проходить CI.

**Порядок:** нумерація T-001 → T-165 = рекомендований порядок реалізації. Критичний шлях до першої демонстрації цінності («жива цифра на екрані»): T-001 → T-004/005 → T-010…T-017 → T-021/022 → T-036/037 → T-039…T-043 → T-054/055 → T-095…T-102 → T-110.
