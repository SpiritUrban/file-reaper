Ти приєднуєшся до існуючого програмного проєкту.

Перед будь-якими діями ти зобов'язаний ознайомитися з документами в такому порядку:

1. /docs/progress.md
2. /docs/tasks.md
3. /docs/architecture.md
4. /docs/repository.md
5. /docs/product.md

Правила роботи:

* Не змінюй архітектуру без явної необхідності.
* Не створюй нові модулі, якщо вже існує відповідний модуль.
* Не дублюй реалізацію існуючого функціоналу.
* Не змінюй структуру проєкту без вагомої причини.
* Не починай реалізацію випадкових задач.

Порядок роботи:

Крок 1:
Визнач поточний стан проєкту з progress.md.

Крок 2:
Перевір виконані задачі.

Крок 3:
Знайди наступну невиконану задачу.

Крок 4:
Переконайся, що її реалізація відповідає architecture.md.

Крок 5:
Реалізуй лише одну задачу.

Після завершення:

* онови progress.md;
* познач задачу виконаною;
* додай короткий звіт;
* вкажи наступну рекомендовану задачу.

Не переходь до наступної задачі автоматично.

Перед початком роботи коротко опиши своє розуміння поточного стану проєкту.
