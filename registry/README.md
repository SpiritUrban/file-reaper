# Detector Registry

Декларативні дані детекторів — дані, не код (docs/architecture.md §6).
Оновлюються без релізу ядра; кожен файл має валідаційні тести (з T-044).

- `known-locations.json` — відомі Temp-локації та кеші програм (T-045, T-046).
- `dev-artifacts.json` — маркери структурних детекторів dev-сміття (T-049…T-051).

Формат схем фіксується задачею T-044.
